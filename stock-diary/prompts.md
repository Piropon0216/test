# プロンプト集（携帯/PCの Claude にコピペ）

携帯やPCの **Claude（Maxプラン）** にそのまま貼って使う定型プロンプトです。API課金は不要。

## 事前準備（どちらかでデータソースを渡す）

- **方法A: GitHubコネクタ** — Claude の設定でこのリポジトリ（`Piropon0216/test`）を接続。
  プロンプト内の「リポジトリの stock-diary/ 配下のファイル」を自動で読めます（web/デスクトップが確実）。
- **方法B: プロジェクト** — Claude.ai で「株式アナリスト」プロジェクトを作り、
  `METHODOLOGY.md` `watchlist.md` `performance.md` を知識として添付。以後その文脈で質問。
- どちらも使えない時は、3ファイルの中身を会話に貼り付けてから下のプロンプトを送ってください。

> ⚠️ いずれも投資助言ではありません。出力は必ず一次情報で確認を。

---

## ① 日次・推奨ランキング更新

```
あなたは私専属の株式アナリストです。まず web検索で本日（日本時間）の
「日本経済」「米国経済」「株式市場」の主要ニュースを調べてください。

次に、リポジトリ stock-diary/ の METHODOLOGY.md（評価7軸と私の投資方針）と
watchlist.md（追跡銘柄）を読み、その基準に厳密に従って、
日本株TOP10・米国株TOP10を rank 付きで作成してください。

各銘柄は「総合スコア / 7軸の内訳 / 推奨理由（当日ニュースと結びつける）/ 主なリスク」を含め、
できる限り出典リンクを添えてください。最後に本日のマクロ要約（3〜5文）も。
これは投資助言ではない前提で、断定を避けリスクにも触れること。
```

## ② 週次・振り返り（精度を上げる肝）

```
リポジトリ stock-diary/performance.md を読んでください。
確認待ち（⏳）の推奨について、web検索で現在の株価/騰落を調べ、
仮説が当たったか（✅/❌/➖）を判定し、表を更新する形で出力してください。

そのうえで「よく当たったパターン」「外したパターンの共通点」を抽出し、
METHODOLOGY.md の評価軸の重みや投資方針をどう調整すべきか、具体案を提案してください。
```

## ③ 個別銘柄の深掘り

```
銘柄: 〇〇（コード/ティッカー）について、web検索で直近のニュース・決算・株価トレンドを調べ、
stock-diary/METHODOLOGY.md の7軸で採点してください。
強気材料・弱気材料・主なリスク・注目すべき今後のカタリストを整理し、
私の投資方針（中長期・リスク中）に照らした総合所見を述べてください。投資助言ではない前提で。
```

## ④ ウォッチリストの棚卸し

```
stock-diary/watchlist.md を読み、web検索で各銘柄の直近の状況を確認してください。
「外す候補（理由つき）」と「新しく入れる候補（テーマ＋理由）」を提案し、
更新後の watchlist.md の表をそのまま出力してください。
```

## ⑤ テーマ起点で探す

```
今、〇〇（例: 電力インフラ / 防衛 / 量子 / 生成AIの周辺）というテーマで
web検索し、関連する日本株・米国株の有望候補を5つずつ、
stock-diary/METHODOLOGY.md の基準で簡易採点して提示してください。
watchlist.md と重複しない新規候補を優先。投資助言ではない前提で。
```
